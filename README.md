Server Monitoring Tool
A lightweight FastAPI application for monitoring servers via SSH and HTTP checks. Designed for easy setup, scalability, and simple server management.

Features
Add servers with SSH credentials (password or private key)
Optional HTTP checks for web services
Async or sync SSH connections for scalable monitoring
Built with FastAPI and Pydantic for validation and clean API design

Requirements
Python 3.10+
uv
 for environment and dependency management
